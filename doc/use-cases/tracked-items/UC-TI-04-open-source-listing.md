# UC-TI-04 — Open a source listing

**Primary actor:** Operator
**Supporting system:** Browser
**Trigger:** The operator chooses an item's open-listing action from the tracked-items page.

## Preconditions

- The tracked-items page shows the item and its source URL.

## Main flow

1. The operator chooses the action to open the Amazon or LeBoncoin listing.
2. The browser opens the stored listing URL in a new tab.

## Postconditions

- The tracked-items page remains open in its original tab.
