# Document or cover build-constrained files in the server dependency check

Status: todo
Source: PR #247, R1-02

**Problem:** `listServerDependencies` (`internal/amazon/amazontest/server_dependencies.go:17`) runs `go list -deps ./cmd/...`, which only resolves files for the current GOOS/GOARCH and default build tags. A helper import in a build-constrained file (for example `//go:build windows` or `_darwin.go`) used by the server would be missed. No such files exist today.

**Suggested work:** Note the limitation in the doc comment of `listServerDependencies` and in TS-TEST-HYG-011 (`doc/specifications/test-suite-hygiene/technical.md`), or, if release targets differ, also run the listing for each release GOOS/GOARCH (and relevant `-tags`).
