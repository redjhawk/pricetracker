# Add a regression test for the nested acrPopover text fallback

Status: todo
Source: PR #368, R2-02

**Problem:** The Amazon rating text fallback (`internal/amazon/collector.go:99-101`) now reads the whole `#acrPopover` element, including nested elements. The only text-fallback case in `internal/amazon/customer_rating_test.go:91` ('rating in the text only') puts `a-icon-alt` as the first child, so it also passed with the earlier code that stopped at the first nested `</span>`. A regression to that cut would go unnoticed.

**Suggested work:** Add a TC-001 case to `TestCustomerRating` in `internal/amazon/customer_rating_test.go` that uses the real nested markup of `internal/amazon/testdata/rating-fr.html` (lines 14-17) without the `title` attribute, and expect rating 45 and count 1234.
