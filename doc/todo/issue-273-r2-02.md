# UC-HTTP-TMO-001: scope postconditions to body-reading endpoints

Status: todo
Source: PR #306, R2-02

**Problem:** The Postconditions of `doc/use-cases/http-server-timeouts/UC-HTTP-TMO-001-slow-client-request-is-dropped.md` (lines 34-35) say without qualification that the request was not handled and no data changed, while the 'Endpoint without a request body' alternative (line 26) has the request handled and its response sent.

**Suggested work:** Scope the postconditions to the main flow, e.g. 'For an endpoint that reads a request body: the connection is closed, the request was not handled and no data changed.'
