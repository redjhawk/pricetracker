# Blocking review comments (round 1)

## R1-01 `internal/amazon/browser_profile_values_test.go:213`

The new cleanup only refuses to delete "" and os.TempDir() itself. Every other path that profileOf("") returns goes to os.RemoveAll, even though the subtest's own location check (line 226,t.Errorf, so the test keeps going) already knows that such a path is wrong. `profile()` also has a branch that returns a real, persistent profile directory (`c.options.ProfileDir`, line 312 of browser.go). Suppose a regression sends the empty-dir case to a default or configured profile (for example ~/.config/... or a folder taken from an environment variable), or returns some other absolute path. Before this change the test would only fail. Now, at the end of the subtest, it would also recursively delete that directory on the developer's or CI machine. This conflicts with FR-TEST-HYG-055 ("never removes anything other than the temporary profile it was given") and with TC-001's corner case that nothing but the temporary profile is targeted. Suggested fix: guard the removal with the same condition as the location check and drop the two special cases, which it already covers (Dir("") is "." and Dir(TempDir) is its parent): `if filepath.Dir(path) != filepath.Clean(os.TempDir()) || !strings.HasPrefix(filepath.Base(path), "pricefollower-browser-") { return }`. All fault injections in no-tests.md (runs 2-7) still behave the same, including the regular-file case of run 5, and a normal run is unaffected. The technical specification's TS-TEST-HYG-071 wording should be updated to match.

Triage: Verified: the t.Cleanup at internal/amazon/browser_profile_values_test.go:212-219 skips only "" and os.TempDir(), so any other path that profile() (internal/amazon/browser.go:304-323) might return after a regression, such as a persistent default profile directory, would be deleted with os.RemoveAll. That breaks FR-TEST-HYG-055 ("never removes anything other than the temporary profile it was given") and risks data on developer and CI machines. Fix: guard the removal with the subtest's own location check (parent is filepath.Clean(os.TempDir()) and the base name has the prefix pricefollower-browser-), and update the wording of TS-TEST-HYG-071 to match.
