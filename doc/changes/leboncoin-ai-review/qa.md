## Coverage and limitations

- Covered: no-token states, format validation, real Claude rejection of a fake token, empty/whitespace/unchanged saves, Amazon exclusion, repeated clicks on the disabled refresh, keyboard reachability, 400 px layout, refresh/back navigation (seeded walk), token absence from browser storage and server output.
- Blocked: every state requiring an accepted token (QA-011), including live review content, progress, history, failure notices, older-price label, rejected-token warning, persistence after restart, and a "saved token unchanged" save. Mocked-UI coverage of these exists in `tests/leboncoin-ai-review.spec.ts` / `tests/claude-token-settings.spec.ts` but does not count as executed interface QA here.
- Not tested: `CLAUDE_UNREACHABLE` (network to Anthropic was available), screen-reader announcements (only ARIA attributes inspected; Carbon's invalid text has no `aria-live`), item deletion of reviews (no reviews exist), concurrency.
- QA-OBS-1 (pre-existing, outside scope): at 400 px the item details page scrolls horizontally because of the listing link (`span.cds--link`), on both Amazon and LeBoncoin pages.
